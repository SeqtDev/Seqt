# Seqt - Disk Sector Fixer

**Seqt** is an open-source utility for scanning and system-level fixing of bad sectors on hard drives (HDD/SSD).

## 🚀 Features
- 🔍 **Disk Check:** Fast scan for bad sectors with progress bar.
- 🛠️ **Fix (System-level):** System-level repair of found errors (sector remapping).
- 💾 **Format:** Full formatting of the selected disk (with confirmation).
- 🌍 **Multilingual:** Russian and English support.
- 💻 **Cross-platform:** Windows (x64)

# Seqt - Программа для исправления битых секторов диска

**Seqt** — это утилита с открытым исходным кодом для поиска и системного исправления битых секторов на жестких дисках (HDD/SSD).

## 🚀 Возможности
- 🔍 **Проверка диска:** Быстрый поиск битых секторов с отображением прогресса.
- 🛠️ **Исправление:** Системное исправление найденных ошибок (переназначение секторов).
- 💾 **Форматирование:** Полное форматирование выбранного диска (с окном подтверждения).
- 🌍 **Мультиязычность:** Поддержка русского и английского языков.
- 💻 **Кроссплатформенность:** Версии для Windows (x64)
